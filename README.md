# Fundamentos de Java para Principiantes

## Descripción del proyecto

Este repositorio contiene los materiales del curso **Fundamentos de Java para Principiantes**, desarrollado por el equipo InnovaCorp.

El curso está dirigido a estudiantes de secundaria de 12 a 17 años sin experiencia previa en programación. Su objetivo es introducir los fundamentos de Java mediante videos educativos y actividades prácticas.

El contenido se desarrolla progresivamente, desde los conceptos básicos de programación hasta una introducción a la programación orientada a objetos.

**No se requiere instalar ningún programa.** Los ejercicios pueden realizarse utilizando herramientas gratuitas disponibles en línea.

## Contenido del curso

El curso comprende siete lecciones:

1. Introducción a la programación y primeros pasos con Java.
2. Variables y tipos de datos.
3. Operadores y expresiones.
4. Estructuras de control.
5. Métodos, parámetros y entrada de datos.
6. Programación orientada a objetos.
7. Arreglos, cadenas de texto y buenas prácticas.

## Organización de los archivos

- **starter-files/**: contiene los archivos iniciales de Java para desarrollar las actividades.
- **completed-examples/**: contiene los ejemplos completos y soluciones de las actividades.
- **scripts/**: contiene los guiones utilizados para desarrollar las lecciones en video.
- **course-plan.md**: contiene el plan del curso, la secuencia de lecciones, los enlaces a los videos y las prácticas, y la información sobre la elaboración en equipo.

## Herramientas necesarias

- **Java:** lenguaje de programación utilizado en el curso.
- **JDoodle:** editor de Java en línea para escribir y ejecutar los ejercicios.
- **YouTube:** plataforma donde se encuentran los videos educativos.
- **GitHub:** plataforma donde se almacena el código fuente y los materiales del curso.

Los estudiantes únicamente necesitan un navegador web y conexión a Internet. No necesitan instalar herramientas de programación.

## Instrucciones de configuración y uso

1. Clona o descarga este repositorio desde GitHub.
2. Abre la carpeta `starter-files/`.
3. Selecciona la carpeta de la lección que deseas desarrollar.
4. Abre el archivo Java correspondiente.
5. Ingresa a [JDoodle - Java Online Compiler](https://www.jdoodle.com/online-java-compiler/).
6. Selecciona Java y copia el código del archivo inicial.
7. Completa las actividades y ejecuta el programa.
8. Compara tu resultado con el ejemplo correspondiente de `completed-examples/`.

Puedes consultar los guiones de las lecciones en la carpeta `scripts/`.
